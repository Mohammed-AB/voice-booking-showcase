# Voice Booking: guided demonstration

A recorded real speech-to-text, booking and spoken-response journey over a fictional calendar. HTTP push-to-talk is supported; this is not a claim of a completed WebRTC call deployment.

## A focused walkthrough

1. **Speak or use a sample.**
2. **inspect the interpretation.**
3. **confirm a sample booking.**

Pause on the evidence at each decision: speech-to-text and spoken replies; structured booking interpretation; confirmation before changes.

## Interactive access

The application is available in Mohammed's local Demo Studio. This repository deliberately does not contain a runnable source distribution. A reviewer can inspect the included materials immediately or request a guided limited-demo session through [the portfolio](https://mohammed-ab.github.io/).

## Boundaries

Fictional bookings only. Live microphone capture depends on browser permission and available allowance. Telephony, physical-device audio and a production LiveKit deployment are not established by this recording.
